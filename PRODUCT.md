# Product

## Platform

web

## Users

Основная аудитория — любой человек, которому нужно, чтобы выбранные сервисы
(Discord, YouTube и т.п.) работали через VPN-интерфейс его домашнего роутера.
Диапазон — от новичка без сетевых знаний («хочу, чтобы Discord работал») до
power user, который пересобирает профили под несколько устройств. Пользователь
сам выбирает уровень вовлечённости: интерфейс обязан иметь режимы (простой
путь по умолчанию, экспертная глубина по запросу). Локализация обязательна:
русский и английский — равноправные случаи вёрстки, копия не хардкодится.

## Product Purpose

Routevane локально собирает проверяемые маршрутные списки без работы
пользователя с IP-адресами: выбрал сервисы, добавил нужные форматы и устройства
— получил опубликованные артефакты, ссылки подписки и/или применение на роутер.
Один список может одновременно питать несколько выводов. Успех: сервис
пользователя работает через нужный интерфейс, и пользователь в это верит,
потому что видел, что именно уехало на каждую цель.

## Positioning

Единственный в RU-нише инструмент, который держит весь путь «сервисы → роутер»
в одном живом локальном UI: конкуренты — Telegram-бот (Domain Mapper),
exe/скрипты (AntiKeen), SSH/CLI (XKeen, itdog) — отдают файл и бросают
пользователя. Механизм, который нельзя скопировать честно: проверяемость
(валидация до публикации, reason-коды, иммутабельные артефакты) и применение с
резервной копией и откатом.

## Operating Context

- Один Go-бинарь обслуживает UI и API на 127.0.0.1:8765; никакого облака и
  аккаунтов. Данные — локальный SQLite.
- Целевые устройства — потребительские роутеры, в первую очередь Keenetic
  (импорт .bat через «Маршрутизация — Пользовательские маршруты», лимит 1024
  строки, привязка к VPN/WAN-интерфейсу), а также иные цели каталога
  (sing-box и др. — формат приходит из каталога).
- Роутер забирает обновления по секретной ссылке подписки; она выдаётся только
  после первой успешной публикации вывода и невосстановима после перезагрузки
  вкладки.
- Применение на устройство идёт по адресу + учётным данным администратора,
  пароль используется однократно либо, только при явном включении авто-доставки,
  хранится в системном хранилище секретов, но не в SQLite и не в браузере.

## Capabilities and Constraints

- Бэкенд уже умеет: каталог целей, устройств, сервисов и категорий; списки с
  несколькими выводами; иммутабельные снапшоты и артефакты; отдельный
  иммутабельный результат каждой попытки публикации; план применения → apply с
  backup и rollback; подписки, расписания и архивирование. Неудачная попытка
  не сдвигает указатель на последний валидный артефакт.
- Контракт клиента запрещает `routing_plan` в ответе сборки; содержимое
  артефакта доступно только по `GET /v1/artifacts/{id}` (сейчас с
  `Content-Disposition: attachment`).
- CSP строгий: `script-src 'self'`, никаких внешних ресурсов.
- Один бинарь, без воркеров и внешних сервисов (инвариант AGENTS.md).
- Терминология продукта: список, вывод, наблюдение (DNS-observation), артефакт,
  подписка, цель (target), устройство, покрытие, reason-код.
- Стек UI существующий: Nuxt/Vue в `web/src` (для этапа реализации).

## Brand Commitments

Пользовательское закрепление (2026-08-21): визуальное направление — не
метафорический «мир», а категорийный стандарт операционной консоли по
интерфейсным референсам. Планка ремесла: Codex-look, near-black консоль,
статус «точка + текст», плотность через выравнивание; из сетевых
инструментов — уровень Tailscale admin console. Исполнять канон в полную
силу, без иронии и скрытых причуд.

## Product Principles

1. UI не врёт: каждое имя, формат и статус приходят из данных, а не из
   предположений экрана; неопределённость показывается как неопределённость.
2. Безопасный автоматический путь очевиден; IP, CIDR, TTL и происхождение —
   в прогрессивной диагностике, а не на главном пути.
3. Доверие через дословность: пользователь может увидеть ровно то, что
   уедет на роутер, до и после применения.
4. Уровень вовлечённости выбирает пользователь: простой режим по умолчанию,
   экспертный — без переустановки картины мира.
5. Высокие ставки получают защиту: одноразовый секрет, пароль администратора
   и перезапись маршрутов не могут быть потеряны или запущены случайно.

## Accessibility & Inclusion

WCAG 2.2 AA как ориентир: цели ≥24px, видимый фокус ≥2px с контрастом 3:1,
секреты копируемы (3.3.8), без повторного ввода уже данных сведений (3.3.7),
каждое состояние различимо текстом, а не только цветом. RU/EN — равные случаи
вёрстки.
