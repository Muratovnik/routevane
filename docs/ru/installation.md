# Установка и обслуживание

Аудитория: пользователи готового приложения. [Краткое руководство](../../README.ru.md#скачать-и-запустить)
описывает первый запуск; этот документ отвечает на вопросы о проверке загрузки,
вариантах запуска, обновлении, резервном копировании, удалении и восстановлении
для обоих дистрибутивов. Сборка из исходного кода описана в отдельной
[инструкции для разработчиков](../../CONTRIBUTING.md) (English).

Ни один дистрибутив не требует Go, Node.js, Python или PowerShell 7.
Минимальные версии операционных систем определяются инструментами Go, которыми
собирается Routevane: пакету для macOS нужна macOS 13 или новее. Пакетов для
Intel Mac и 32-битных систем нет; официального контейнера или установщика для
менеджера служб тоже нет. Автоматические тесты интерфейса проверяют Chromium;
другие браузеры отдельно не проверялись.

## Проверить загрузку

Скачайте `SHA256SUMS` из того же релиза, что и ваш файл. В нём указан ожидаемый
SHA-256 для каждого архива и для установщика Windows. Эти проверки используют
системные утилиты, а не инструменты разработки. Замените имя файла в примере на
имя скачанного файла.

В Windows откройте PowerShell в папке загрузки:

```powershell
(Get-FileHash ./Routevane-X.Y.Z-x64-setup.exe -Algorithm SHA256).Hash
```

Откройте `SHA256SUMS` в текстовом редакторе и сравните полный хеш со строкой
именно для этого файла. Регистр букв не важен.

В Linux, когда ZIP и `SHA256SUMS` лежат в текущей папке:

```sh
sha256sum --ignore-missing -c SHA256SUMS
```

Убедитесь, что возле вашего архива написано `OK`. В macOS:

```sh
shasum -a 256 routevane-vX.Y.Z-darwin-arm64.zip
```

Сравните полный хеш со строкой для этого файла в `SHA256SUMS`. Если строки нет
или хеши отличаются, файл запускать нельзя. Контрольные суммы обнаруживают
изменённые байты. Дополнительная проверка подписанной идентичности сборки
описана в [английской инструкции по provenance](../releasing.md#verify-a-download);
для неё нужен GitHub CLI, но не для запуска приложения.

## Настольное приложение (Windows)

### Установка

Если в релизе есть `Routevane-X.Y.Z-x64-setup.exe`, запустите его. Приложение
устанавливается для текущего пользователя; права администратора и отдельный
браузер не нужны. Релизы без этого файла содержат только пакет CLI.

Установщик пока не подписан, поэтому Windows SmartScreen может сообщить о
неизвестном издателе. Сначала проверьте контрольную сумму, затем выберите
**«Подробнее → Выполнить в любом случае»**.

Маршруты, подключения и настройки интерфейса хранятся в `%APPDATA%\Routevane\`,
база данных лежит в подпапке `data\`, вне папки установки. Закрытие окна
скрывает Routevane в трей; **«Выйти»** в меню трея завершает приложение.

### Обновление

Установленное приложение проверяет новые стабильные версии в
[GitHub Releases](https://github.com/Muratovnik/routevane/releases) вскоре после
запуска, каждые четыре часа и после выхода компьютера из сна. Если версия
найдена, внизу левого меню появляется **«Обновить»**. Сохраните изменения и
нажмите кнопку: Routevane скачает установщик, установит его и перезапустится.
При ошибке загрузки текущая версия продолжит работать, а кнопка предложит
повторить попытку. Закрытие окна или выход сами по себе ничего не скачивают и
не устанавливают.

Можно также скачать новый установщик со страницы релиза, выбрать **«Выйти»** в
трее и запустить его. Удалять предыдущую версию не нужно: данные остаются в
`%APPDATA%\Routevane\`.

### Резервное копирование и восстановление

Перед копированием данных выберите **«Выйти»** в трее; закрытие окна лишь
скрывает его. Скопируйте папку `%APPDATA%\Routevane\` целиком. Для
восстановления установите ту же или более новую версию, завершите её, замените
папку своей копией и запустите Routevane снова. Не открывайте базу,
мигрированную новой версией, более старой версией.

Данные пакета CLI не переносятся автоматически. Чтобы перенести маршруты из
установки CLI, воспользуйтесь [переносом конфигурации](usage.md#перенос-конфигурации-на-другой-компьютер),
заново введите пароли устройств и опубликуйте каждое подключение.

### Удаление

Перед удалением выключите автоматическую доставку для устройств в разделе
**«Подключения»**, чтобы сохранённые пароли были удалены из хранилища учётных
данных Windows. Затем завершите Routevane и удалите его через
**«Параметры → Приложения»**. Деинсталлятор сохраняет `%APPDATA%\Routevane\`;
удалите эту папку сами, если не хотите хранить маршруты. Удаление Routevane
**не** отменяет маршруты, уже применённые на устройстве.

## Пакет CLI (Windows, Linux, macOS)

### Что находится в загрузке

Скачивайте ZIP для своей операционной системы из [Releases](https://github.com/Muratovnik/routevane/releases/latest),
а не архив GitHub **Source code**. Распакуйте всю папку приложения:

| Файл | Назначение |
| --- | --- |
| `start-routevane.cmd` или `start-routevane.sh` | Запускает приложение и открывает его интерфейс в браузере |
| `routevane.exe` или `routevane` | Приложение, включая веб-интерфейс и программу командной строки |
| `catalog/` | Поставляемые списки и описания форматов вывода |
| `README.txt` | Автономная инструкция по запуску, остановке, обновлению и восстановлению |
| `LICENSE`, `THIRD_PARTY_NOTICES.txt`, `SBOM.spdx.json` | Лицензия и сведения о включённых зависимостях |

Храните эти файлы вместе. Файл запуска использует распакованную папку и для
каталога, и для ваших данных независимо от того, откуда он запущен. Он не
устанавливает системную службу и не настраивает запуск при входе в систему.
Windows выполняет `.cmd` встроенным командным интерпретатором, Linux и macOS —
`sh`. Для интерфейса используйте обычный браузер. Необязательное
[обнаружение через браузер](usage.md#добавление-сервиса-по-url) требует явно
настроенного браузера семейства Chromium, но не нужно для запуска приложения
или работы с поставляемыми списками.

### Варианты запуска

Чтобы выбрать другой порт, выполните команду из распакованной папки приложения:

```powershell
./start-routevane.cmd 9000
```

В Linux или macOS:

```sh
sh ./start-routevane.sh 9000
```

После этого откройте `http://127.0.0.1:9000`. Значение
`ROUTEVANE_NO_BROWSER=1`, заданное перед запуском, запрещает автоматическое
открытие браузера. О прямом запуске бинарного файла рассказано в разделе
[«Локальная служба подписок»](usage.md#локальная-служба-подписок).

Интерфейс и подписки слушают только этот компьютер. Роутер или другой компьютер
не смогут получить URL подписки с `127.0.0.1`. Для таких устройств используйте
выгрузку файла или доступную интеграцию доставки; не открывайте локальную службу
в сеть как обходной путь.

### Обновление и резервное копирование

Routevane создаёт `data/` рядом с файлом запуска. В этой папке хранятся база,
история публикаций и созданные файлы. Это приватные данные, а не кэш.

1. Остановите Routevane сочетанием Ctrl+C перед созданием копии данных.
2. Скопируйте `data/` и все ваши изменения в `catalog/`.
3. Проверьте и распакуйте новый релиз в отдельную папку.
4. Скопируйте `data/` в новую папку. Изменения каталога просмотрите и объедините,
   а не заменяйте новый каталог старым целиком.
5. Запустите новую версию и проверьте маршруты. Сохраните старую папку и копию,
   сделанную после остановки, пока не убедитесь, что новая версия работает.

Чтобы откатиться, используйте старую версию с копией, созданной до обновления.
Не открывайте базу, мигрированную новой версией, старым бинарным файлом.

### Удаление

Перед удалением выключите автоматическую доставку для устройств в разделе
**«Подключения»**, чтобы сохранённые пароли были удалены из хранилища учётных
данных операционной системы. Затем остановите Routevane, сохраните нужные данные
и удалите распакованную папку. Вместе с ней удаляются локальные данные. Уже
применённые к устройству маршруты это **не** отменяет.

## Устранение неполадок

- **Страница не открывается (пакет CLI):** не закрывайте консоль и прочитайте
  ошибку. Попробуйте открыть напечатанный адрес вручную. В распакованной папке
  выполните `./routevane version` (`./routevane.exe version` в Windows),
  чтобы проверить версию, и откройте `http://127.0.0.1:8765/health`, чтобы
  увидеть `status: ok`. Если выбрали другой порт, используйте его.
- **Routevane не запустился или его служба остановилась (настольное
  приложение):** возможно, другая программа использует его папку данных или
  порт. Завершите другие экземпляры Routevane и запустите приложение снова.
- **Порт уже занят:** остановите известный экземпляр Routevane или выберите другой
  порт. Не завершайте неопознанный процесс.
- **EXE на мгновение открывает консоль и закрывается:** используйте
  `start-routevane.cmd`. Исполняемый файл без команды показывает справку CLI, а
  не браузерный интерфейс.
- **Нет бинарного файла или каталога:** распакуйте архив целиком; не переносите
  отдельно только файл запуска или исполняемый файл.
- **Инструкция требует Go, Node.js или Python:** это инструкция для разработки
  из исходного кода. Чтобы пользоваться готовым приложением, скачайте релиз.
- **Обновление не скачивается:** текущая версия продолжает работать. Нажмите
  **«Обновить»** позже или установите новую версию вручную со страницы релиза.
- **Потеряна ссылка подписки:** её секрет восстановить нельзя. После публикации
  можно создать другое подключение с новой ссылкой, но старая при этом не
  отзывается. Ротация и отзыв токенов пока не реализованы.

В сообщении об ошибке укажите версию, операционную систему, дистрибутив
(настольное приложение или пакет CLI) и относящуюся к делу ошибку. Не
публикуйте базу данных, URL подписок или пароли устройств. Об уязвимостях
сообщайте через [закрытый канал безопасности](../../SECURITY.md) (English).
