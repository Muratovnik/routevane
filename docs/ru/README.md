# Документация Routevane на русском языке

Канонической остаётся [документация на английском языке](../README.md).
Руководства на русском языке предназначены для пользователей готового
приложения.

| Задача | Документ |
| --- | --- |

| Проверить загрузку, обновить, создать резервную копию, удалить или устранить неполадку | [Установка и обслуживание](installation.md) |
| Перенести настройки, профили и подключения на другой компьютер | [Перенос конфигурации](usage.md#перенос-конфигурации-на-другой-компьютер) |
| Использовать команды CLI, обнаружение или конкретный формат | [Расширенное использование](usage.md) |
| Собрать приложение из исходного кода | [Contributing](../../CONTRIBUTING.md) (English) |
| Установить или разрабатывать плагин | [Примеры](../../examples/plugins/README.md) и [SDK](../../sdk/routevaneplugin/README.md) (English) |
| Узнать, что изменилось между версиями | [Журнал изменений](../../CHANGELOG.md) (English) |
| Сообщить об уязвимости | [Политика безопасности](../../SECURITY.md) (English) |

Требования, архитектура, порядок выпуска релизов и решения проекта описаны
только в [английском указателе](../README.md): эти документы адресованы
участникам и сопровождающим проекта, а не установке и использованию приложения.
