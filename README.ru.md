<h1 align="center">Routevane</h1>
<p align="center">Списки маршрутизации для роутера или VPN-клиента, собранные на вашем компьютере.</p>

Routevane создаёт списки маршрутизации для роутера или VPN-клиента. Выберите
списки и категории из поставляемой библиотеки, объедините их в профиль и
выгрузите результат в формате, который понимает ваше устройство. Списки
обновляются вручную или по расписанию.

> [!NOTE]
> Routevane готовит правила маршрутизации. Он не предоставляет VPN-подключение,
> не требует учётной записи и облачного сервиса: всё работает на вашем компьютере.

- **Готовые списки.** Популярные сервисы, сгруппированные по категориям.
  Добавляйте собственные списки или соберите новый по адресу сервиса с
  помощью браузера.
- **Профили вместо таблиц.** Объединяйте списки и категории в профиль.
  Приоритет списков разрешает пересекающиеся назначения, а прогноз показывает,
  сколько правил соберёт каждый формат, ещё до сборки.
- **Шесть форматов вывода.** Маршруты IPv4 для Keenetic, группы FQDN для
  Keenetic, sing-box, OpenWrt, MikroTik и AmneziaVPN. Один профиль может
  публиковаться в нескольких форматах.
- **Безопасные обновления.** Каждый публикуемый файл сначала проверяется. Если
  сборка по расписанию не удалась, остаётся доступен предыдущий корректный файл.
- **Явная доставка.** Ссылки подписки работают только на этом компьютере.
  Отправка правил на роутер Keenetic или в локальный sing-box включается
  отдельным действием.
- **Локально и на двух языках.** Настольное приложение для Windows, пакет
  командной строки для Windows, Linux и macOS, интерфейс на русском и
  английском языках.

## Скачать и запустить

Текущая схема релиза, введённая в `v0.1.7`, содержит перечисленные ниже файлы.
В более ранних релизах есть пакеты CLI, но нет установщика настольного
приложения. Скачивайте файлы из раздела **Assets** на
[странице релизов](https://github.com/Muratovnik/routevane/releases/latest), а
не архив **Source code**. Файл `SHA256SUMS` из того же релиза позволяет
[проверить загрузку](docs/ru/installation.md#проверить-загрузку).

| Дистрибутив | Платформа | Файл |
| --- | --- | --- |
| Настольное приложение | Windows x64 | `Routevane-X.Y.Z-x64-setup.exe` |
| Пакет CLI | Windows x64 | `routevane-vX.Y.Z-windows-amd64.zip` |
| Пакет CLI | Windows ARM64 | `routevane-vX.Y.Z-windows-arm64.zip` |
| Пакет CLI | Linux x64 | `routevane-vX.Y.Z-linux-amd64.zip` |
| Пакет CLI | Linux ARM64 | `routevane-vX.Y.Z-linux-arm64.zip` |
| Пакет CLI | macOS 13 и новее, Apple silicon | `routevane-vX.Y.Z-darwin-arm64.zip` |

Ни один дистрибутив не требует Go, Node.js, Python или инструментов сборки.
Пакетов для Intel Mac и 32-битных систем нет.

### Настольное приложение (Windows)

1. Скачайте `Routevane-X.Y.Z-x64-setup.exe` и запустите его. Приложение
   устанавливается для текущего пользователя и не требует прав администратора.
2. Установщик пока не подписан, поэтому Windows SmartScreen может предупредить
   о неизвестном издателе. Сначала проверьте контрольную сумму, затем выберите
   **«Подробнее → Выполнить в любом случае»**.
3. Routevane откроется в собственном окне.

Закрытие окна скрывает Routevane в трей; обновление списков по расписанию
продолжается. **«Открыть Routevane»** в меню трея возвращает окно, **«Выйти»**
завершает приложение. Когда опубликована новая версия, внизу левого меню
появляется **«Обновить»**: один щелчок скачивает, устанавливает и перезапускает
приложение. Профили и настройки хранятся в `%APPDATA%\Routevane\`. Подробнее в
разделе [установка, обновление и резервные копии настольного приложения](docs/ru/installation.md#настольное-приложение-windows).

### Пакет CLI (Windows, Linux, macOS)

Пакет запускает Routevane как локальную службу и открывает интерфейс в вашем
браузере.

1. Скачайте ZIP для своей платформы и распакуйте папку целиком.
2. Запустите. В Windows дважды щёлкните **`start-routevane.cmd`**. В Linux и
   macOS откройте терминал в этой папке и выполните:

   ```sh
   sh ./start-routevane.sh
   ```

3. Откройте **http://127.0.0.1:8765**, если браузер не открылся сам.

Пока работаете, держите окно консоли открытым; чтобы остановить программу,
нажмите в нём **Ctrl+C**. Данные создаются в папке `data/` рядом с файлом
запуска. Храните исполняемый файл `routevane` вместе с файлом запуска и папкой
`catalog/`: при двойном щелчке по нему самому выводится справка командной
строки, а не интерфейс. Подробнее в разделе
[варианты запуска, обновление и резервные копии](docs/ru/installation.md#пакет-cli-windows-linux-macos).

## Собрать первый профиль

Routevane оперирует четырьмя понятиями. **Список** содержит назначения: домены,
адреса, сети. **Категория** объединяет списки. **Профиль** составляется из
списков и категорий. **Подключение** публикует профиль в одном формате,
при необходимости на одно устройство, и владеет ссылкой подписки этого формата.

1. Откройте **«Списки»**, чтобы увидеть поставляемую библиотеку.
2. Откройте **«Профили»** и выберите **«Собрать профиль»**. Отметьте списки или
   целые категории и выберите формат своего роутера или приложения. Прогноз
   рядом с каждым форматом показывает, сколько правил он соберёт.
3. После первой успешной сборки сохраните ссылку подписки, пока она показана,
   либо скачайте файл в разделе **«Подключения»**.

> [!WARNING]
> Секрет из ссылки подписки показывается один раз и не может быть показан
> повторно. Ссылки подписки работают только на компьютере, где запущен
> Routevane; роутер не сможет их получить.

Профиль может публиковаться в нескольких форматах. Если обновление по
расписанию не удалось, остаётся доступен последний корректный файл. Отправка
правил на устройство является отдельным явным действием; автоматическая
доставка выключена, пока вы не включите её в разделе **«Подключения»**.

## Поддерживаемые форматы

| Формат | Как попадает на устройство | Что проверено |
| --- | --- | --- |
| Маршруты IPv4 для Keenetic | Импорт BAT-файла или доставка на роутер | Тесты протокола; физический роутер ещё нет |
| Группы FQDN для Keenetic (KeeneticOS 5.0+) | Импорт через CLI или доставка на роутер | Тесты протокола; физический роутер ещё нет |
| Набор правил sing-box (source) | JSON-файл или доставка в локальный sing-box | Корректность файла; перезагрузка на лету не проверена |
| OpenWrt dnsmasq nftset | Ручная установка | Рендеринг; интеграция с межсетевым экраном не проверена |
| Списки адресов MikroTik | Ручной импорт скрипта | Рендеринг; выполнение на устройстве не проверено |
| Список split tunnel для AmneziaVPN | Импорт JSON | Рендеринг; импорт в клиент не проверен |

Перед применением правил на устройстве прочтите
[руководство по форматам и ограничениям](docs/ru/usage.md#поддерживаемые-форматы).

## Состояние проекта

Routevane находится в версии `0.y.z`: несовместимое изменение повышает минорную
версию, всё остальное повышает патч. Рендеринг и проверка каждого формата,
браузерный интерфейс, жизненный цикл настольного приложения в Windows и
обновление через установщик покрыты текущим набором релизных проверок.
Не проверено: работа на физических устройствах Keenetic, OpenWrt, MikroTik и
AmneziaVPN, перезагрузка sing-box на лету и подписанный установщик. Настольные
пакеты существуют только для Windows. Подробнее в разделе
[открытая работа и ограничения](docs/requirements.md#open-work-and-limits)
(English) и в [журнале изменений](CHANGELOG.md) (English).
