# Routevane

<img src="web/public/routevane-logo.svg" alt="Routevane" width="56">

[English documentation](README.md)

Routevane создаёт списки маршрутизации для роутера или VPN-клиента. Выберите
сервисы и категории, объедините их в маршрут и выгрузите результат в формате,
который понимает ваше устройство. Списки можно обновлять вручную или по
расписанию.

Приложение работает на вашем компьютере; интерфейс доступен на русском и
английском языках. Учётная запись и облачный сервис не нужны. Routevane готовит
правила маршрутизации, но сам VPN-подключение не предоставляет.

## Скачать и запустить

Electron-приложение открывает Routevane в собственном окне со встроенным браузерным
движком. Крестик скрывает окно в трей; **«Открыть Routevane»** возвращает его,
а **«Выйти»** завершает приложение и его фоновую работу. Повторный запуск
возвращает уже открытое окно.

Соберите desktop-пакет по [инструкции для разработчика](CONTRIBUTING.md#desktop-application).
В Windows откройте `Routevane.exe` в полученной папке приложения; храните папку
целиком. Если в релизе есть `Routevane-X.Y.Z-x64-setup.exe`, можно установить
приложение и обновлять его кнопкой **«Обновить»** внизу левого меню либо запуском
нового установщика вручную. Подробнее — в [руководстве по установке](docs/ru/installation.md).

Ниже — инструкции для отдельно поставляемой **версии командной строки** с
браузерным интерфейсом.

Релиз готов к работе: **Go, Node.js, Python и инструменты сборки не нужны**.
Нужен только браузер.

### Windows

1. Откройте [последний релиз](https://github.com/Muratovnik/routevane/releases/latest).
   В разделе **Assets** скачайте ZIP с окончанием `windows-amd64.zip` для
   большинства ПК либо `windows-arm64.zip` для Windows на ARM. Не выбирайте
   **Source code**.
2. Распакуйте ZIP целиком в папку, куда у вас есть право записи.
3. Дважды щёлкните **`start-routevane.cmd`** в распакованной папке.

`start-routevane.cmd` — включённый в релиз запускатель, а не установщик. Он
запускает приложение и открывает интерфейс в браузере. Храните его вместе с
`routing-agent.exe` и `catalog/`: сам EXE — программа командной строки и при
двойном щелчке интерфейс не открывает.

### Linux и macOS

Скачайте ZIP для своего компьютера из того же релиза:

| Компьютер | Окончание архива |
| --- | --- |
| Linux x64 | `linux-amd64.zip` |
| Linux ARM64 | `linux-arm64.zip` |
| Mac с Apple silicon, macOS 13+ | `darwin-arm64.zip` |

Распакуйте архив, откройте терминал в папке приложения и выполните:

```sh
sh ./start-routevane.sh
```

На всех платформах интерфейс доступен по адресу **http://127.0.0.1:8765**. Если
он не открылся сам, откройте этот адрес вручную. Пока используете Routevane,
держите окно консоли открытым; чтобы остановить программу, нажмите в нём
**Ctrl+C**.

[Проверка загрузки, обновление и устранение неполадок](docs/ru/installation.md)
описаны отдельно.

## Создать первый маршрут

1. Откройте **«Списки»**, чтобы увидеть поставляемые сервисы и категории.
2. Откройте **«Маршруты → Создать маршрут»**, выберите нужные списки и формат
   вывода.
3. После успешной сборки сохраните ссылку подписки, когда она будет показана,
   либо откройте **«Подключение»**, чтобы скачать файл. Секрет из ссылки нельзя
   показать повторно. Подписки работают только на том компьютере, где запущен
   Routevane.

К одному маршруту можно добавить несколько форматов. Если обновление не
получилось, остаётся доступным последний корректный файл. Отправка правил на
устройство — отдельное явное действие; автоматическая доставка выключена, пока
вы сами её не включите.

## Поддерживаемые форматы

Доступен экспорт для **Keenetic**, **sing-box**, **OpenWrt**, **MikroTik** и
**AmneziaVPN**. Для Keenetic и локального sing-box также есть интеграции
доставки.

Форматы проверяются тестами, но работа на физическом роутере и принятие файла
сторонним клиентом ещё не подтверждены. Перед применением правил на устройстве
прочтите [руководство по форматам и ограничениям](docs/ru/usage.md#поддерживаемые-форматы).
